# KcKTV (Android TV)

Android TV kutuları için basit bir IPTV oynatıcı. Uygulamanın içinde hiçbir kanal yoktur; kendi sağlayıcının bilgilerini girersin.

## Özellikler
- Kullanıcı adı ile giriş (Xtream: sunucu adresi, kullanıcı adı, şifre) ya da M3U linki ile giriş
- Kategoriler, arama, favoriler (OK tuşuna basılı tut)
- Yayın akışı (Xtream hesaplarında: şimdi / sonra)
- Kumandayla kullanım: ▲ ▼ kanal değiştir, OK bilgi, Geri listeye dön
- .ts açılmazsa otomatik olarak .m3u8 dener

## APK nasıl alınır
Her yüklemede GitHub otomatik derler. Depo sayfasında sağ taraftaki **Releases** bölümünden `IPTV-Player.apk` dosyasını indir.

## Kutuya kurulum
1. Kutuda **Downloader** uygulamasını kur (Google Play'de var).
2. Ayarlar → Uygulamalar → Downloader → **Bilinmeyen kaynaklardan yükleme** izni ver.
3. Downloader'da APK'nın linkini aç ve kur.
